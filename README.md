## 先分清你要的是“代理”，还是“带住宅 IP 的机器”

这决定了 SixtyNet 适不适合你，也是搜“住宅 IP 代理”的人最容易踩空的地方。

代理服务商卖的是接入凭证。付款后你拿到地址、端口、用户名和密码，填进指纹浏览器、脚本或云手机就能用，协议一般是 HTTP(S) 或 SOCKS5。GetIPProxy 这类按 IP 卖的、IPStar 这类按流量卖的，都是这个形态。

SixtyNet 卖的是 VPS。你拿到的是这台机器的 root 登录信息，IP 本身是住宅属性。要把它当代理用，得自己在机器上装一个支持 SOCKS5 或 HTTP 的服务端，再配到客户端里去。代理常用端口不在 80 和 443 上，所以自建代理不受那两个端口限制；真正受影响的是建站，想用这台机器直接跑网站是不行的。

如果你只是想要一个能复制粘贴进指纹浏览器的代理，SixtyNet 会让你多绕一圈，价格也不划算。如果本来就要一台海外机器做自动化、跑环境、挂长期账号，住宅 IP 是额外的好处，那它值。

## 静态还是动态，按 IP 还是按流量

这两组选择各有明确的分界线，按你的使用方式对号入座就行。

**静态与动态**：静态住宅每次连接都是同一个出口 IP，不随请求轮换。动态住宅按时间、请求数或 Session 换 IP，请求 A 走 IP1，请求 B 走 IP2。SixtyNet 属于静态，一整台机器一个固定住宅出口。

**按 IP 与按流量**：按 IP 计费通常意味着独享、不限流量，成本随 IP 数量线性上涨，适合长期固定出口。按流量计费入门门槛低，用多少付多少，适合大量短请求。SixtyNet 是第三条：按月付整机，含一个固定流量额度（5TB 到 40TB），超了要看清流量政策。

落到具体人身上：

- 一个店铺、一个主账号、一套浏览器环境长期用，选静态，出口不能变。
- 批量采集、比价、看不同地区的搜索结果，选动态按流量，静态出口反而拖慢效率。
- 要做几十上百个独立出口的社媒矩阵，按 IP 买更合适。GetIPProxy 美国静态 IP 折后 $3.15/个/30 天，SixtyNet 一台机器 $25/月起只给一个住宅 IP，矩阵场景下成本差好几倍。

所以 SixtyNet 的定位很清楚：出口数量少、但对出口质量和使用方式要求高的场景。

## 常见问题

**续费会不会换 IP？** SixtyNet 官网没有明文承诺保留。行业通行做法是到期前续费才能延续原 IP，过期就释放。想长期绑账号，提前几天续。

**IP 是独享的吗？** 官网页面只写了 Residential IP，没有明确写独享或共享。从产品形态看是一台机器分配一个住宅 IP，但这一点建议开工单确认，别自己假设。

**80 和 443 端口不开放，会影响什么？** 影响建站和需要标准 Web 端口的服务。自建代理、跑自动化、看流媒体、登账号都不受影响。

**付款后拿到什么？** 一台 VPS 的登录信息（IP、SSH 端口、root 密码），不是代理地址和账号密码。要当代理用得自己装服务端。

**能退款吗？** 第三方测评提到 3 天内可申请退款，需符合退款条款。这是第三方说法，下单前到官网退款政策页自己确认一遍。

**现在能买吗？** 我抓取时四个档位都是 0 Available，处于缺货状态。先点进去看库存再决定。

**这家靠谱吗？** 公开测评提到 SixtyNet 成立时间不长，主打洛杉矶机房，住宅 IP 是它的差异化产品线。新商家的长期稳定性没有足够长的记录可查，别一次性压太长的周期。
